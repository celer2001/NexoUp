 # Nombre del proyecto 
NexoUp es una aplicación diseñada para facilitar la gestión de negocios minoristas, permitiendo controlar ventas, stock, pagos y finanzas de una manera simple y eficiente.

# Descripción 
NexoUp es una aplicación orientada a emprendedores y pequeños comerciantes que buscan simplificar la administración de sus negocios. 
La plataforma integra múltiples funcionalidades en un solo lugar, permitiendo gestionar ventas, registrar distintos medios de pago y llevar un control detallado del flujo del dinero.
Además, ofrece herramientas de gestión de inventario, incluyendo control de stock, alertas de stock mínimo y seguimiento de fechas de vencimiento de producto.
También permite registrar gastos asociados a proveedores, facilitando una visión completa de la situación financiera del negocio. 
El objetivo principal de NexoUp es hacer que la gestión de un negocio, incluso siendo pequeño, no sea complicado, brindando una solución accesible, intuitiva y fácil de usar para cualquier emprendedor
